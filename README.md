# Uygar Ceylan · Base Camp

My personal site: an Arctic research hut where every object opens part of my work.

- `index.html`: the base camp (boot screen, the hut, project panels)
- `classic.html`: the classic one-page version of the site (linked from the "Classic site" button)

Both pages are single self-contained HTML files with images built in, so there is no build step. Deploy on Vercel as a static site (framework preset: Other).
